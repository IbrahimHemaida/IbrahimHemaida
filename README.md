### 🚀 Featured Case Studies & Projects

#### 🩺 Nabed Connect & Nabed TV (Healthcare IoT Ecosystem)
* **The Challenge:** Building a nationwide healthcare platform ensuring 99.9% content availability across restricted clinical networks.
* **The Solution:** Architected an offline-first system with local persistence and MQTT-based device synchronization. Built a custom Kiosk Launcher with hardware-level MAC activation.
* **Impact:** Reduced device activation time by 60% and enhanced multi-patient session management by 30% through a WCAG accessibility-first tablet UI redesign.

#### 🤖 RD Labs (AI Assistant & Caller ID)
* **The Challenge:** Modernizing a high-traffic application (3M+ users) while maintaining a minimal crash rate and smooth UI performance.
* **The Solution:** Led a full-stack migration to Hilt, Coroutines, and MVVM Clean Architecture with modular configurations. Integrated on-device NLP for real-time processing.
* **Impact:** Reduced app crash rates by 15% (Firebase Crashlytics) and cut average UI jank by 40% (Android Profiler & Systrace).

#### 🏨 Savvy (Smart Hotel Automation)
* **The Challenge:** Seamlessly automating guest experiences via IoT controls without sacrificing interface simplicity.
* **The Solution:** Integrated PMS and VingCard SDKs over Bluetooth and NFC protocols, wrapping them in an intuitive UI designed for guests with mobility limitations.
* **Impact:** Automated guest workflows across 5+ luxury properties and slashed service request resolution times by 35%.
